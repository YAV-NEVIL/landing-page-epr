# ⚡ LA MÉTHODE EPR — Landing Page Cinématographique Haute Conversion

> **Système d'Exploitation pour Électriciens & PME Africaines**  
> Conçu pour transformer un artisan électricien en chef d'entreprise rentable et respecté.

---

## 🚀 Présentation

Cette landing page haute-fidélité présente l'offre unique complète de **La Méthode EPR** (par l'Ir. Jean Philippe) :
* 📖 **Livre Fondateur** (PDF 222 pages — 9 Piliers fondamentaux)
* 📊 **35 Fichiers Excel Automatisés** (Moteur de gestion des stocks VBA `EPR Stock V3`, Cockpit rentabilité chantier, Calculateur de marge, Taux horaire, Trésorerie)
* 📄 **30 Outils Administratifs & Juridiques Word** (Contrats de sous-traitance, Fiches avenants travaux supplémentaires, PV de réception, relances impayés)
* 🎙️ **Note Vocale Haute Définition** de l'Ingénieur en lecture automatique interactive
* ⚡ **Tunnel de commande Express Chariow** intégré avec support des paiements mobiles (Wave, Orange Money, MTN MoMo, Moov, Airtel) et carte bancaire

---

## 🛠️ Stack Technique

* **Framework :** [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
* **Styles :** [Tailwind CSS v3.4](https://tailwindcss.com/)
* **Animations :** [GSAP 3](https://greensock.com/gsap/) (ScrollTrigger) + Animations personnalisées
* **Icônes :** [Lucide React](https://lucide.dev/)
* **Paiement :** Intégration passerelle officielle [Chariow](https://chariow.com/)

---

## 💻 Démarrage en local

```bash
# Installation des dépendances
npm install

# Lancement du serveur de développement
npm run dev

# Build de production
npm run build
```
